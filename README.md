# 💼 Calculadora de Comissão e Bonificação de Vendas

Aplicação de console desenvolvida em **Java** para automatizar o cálculo de comissões e bonificações de consultores de vendas com base em regras de negócio.

---

## 📌 Funcionalidades
- Leitura de dados de entrada via terminal (`Scanner`).
- Cálculo percentual da comissão sobre o volume vendido.
- Aplicação de bonificação por meta atingida (vendas $\ge$ R$ 50.000,00 recebem bônus de R$ 1.000,00).
- Demonstrativo final com formatação monetária de duas casas decimais.
